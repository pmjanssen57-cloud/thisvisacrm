THiS CRM v0.16.3 rollback

Immediate application rollback:
- Redeploy THiS-CRM-v0.16.2-Original-Styling-Archiving.zip to return to the prior release.
- v0.16.3 adds no database migration and does not alter any previously applied migration.
- The intake/contact Archive data model remains the same as v0.16.2.

What v0.16.3 changes:
- Adds an Unassigned clients filter so client records created without a primary adviser can be recovered easily.
- Prevents future intake conversion until an adviser is assigned.
- Corrects Agreement Studio A4 printing so A4 page containers do not fragment across print pages.
- Removes the artificial final-page signoff reservation that could create a mostly blank page.

No schema rollback is required. Do not edit any already-applied migration.
