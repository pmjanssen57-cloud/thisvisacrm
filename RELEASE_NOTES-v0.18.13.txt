THiS CRM v0.18.13 - Simplified Instructions Studio
23 November 2026

BASELINE: THiS CRM v0.18.12 (Document Warning Fix).

NEW WORKFLOW:
- Adds a prominent starting-point selector to the existing Instructions Studio:
  Standard template, Copy an existing guide, or Start from scratch.
- Adds Basic and Advanced editing views. Basic is the default, focused on everyday document, client and section editing. Advanced retains the existing full controls. The mode preference is local to the browser.
- Preserves all existing standard and published masters, client drafts, blank guide creation, reusable blocks, live preview, PDFs and complex editor options. No template or database schema migration.
- Adds a single Review before issue action in the builder header. It surfaces the existing outstanding-issues warning, if any, and otherwise opens the existing output-settings/review workflow. Does not introduce a competing validation engine.
- Adds guarded draft autosave after user-originated changes (6.5 seconds of inactivity). The existing Save draft button and CRM snapshot mechanism remain the authoritative persistence routes. Autosave never fires while initial loading is incomplete, a dialog is open, or the editor is in failed-load state.
- Tidies the creation screen and advances to appropriate existing guided controls rather than duplicating the document engine.

SCOPE:
- Adds a new self-contained instructions-simplified-v01813.js presentation controller and scoped CSS.
- Changes instructions-studio.html to load the new script and bust the Instructions Builder CSS cache.
- Does not change underlying client data shape, policy content, template versions, backend services, PDFs or other CRM functions.

VALIDATION:
- Syntax checked new JS; source HTML includes expected script and stylesheet; ZIP archive integrity checked.
- Local browser end-to-end test was attempted but Chromium navigation was blocked by environment restrictions; production Vite build and real Netlify/CRM data-save tests remain unverified.

DEPLOYMENT:
- Preview deploy and test creating standard instructions, switching to blank, duplicating an existing guide, Basic/Advanced toggle, issue review, saving/reopening a draft and PDF output.
- For shared/client records verify autosave persists after editing and a manual save continues to work.
- Do not issue client instructions before confirming loaded draft integrity and full document preview.

ROLLBACK: THiS-CRM-v0.18.12.zip. This is a code-only, backward-compatible release; rollback needs no SQL migration.
