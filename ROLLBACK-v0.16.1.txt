THiS CRM v0.16.1 rollback

Immediate rollback package
Redeploy the complete THiS-CRM-v0.16.0-HuB-Visual-Refresh.zip package.

Database
v0.16.1 does not add or alter a database migration, so no database/schema rollback is required. Do not edit any already-applied migration.

Archived records
Records archived while v0.16.1 is running remain in the existing intake_enquiries table with status `Archived`. The v0.16.0 interface does not provide the new Archive workspace and normalises `Archived` to Contacted for display, so those records can temporarily reappear in dealt-with queues. The database status is not rewritten unless a record is subsequently saved. Redeploying v0.16.1 makes the Archive visible again. Purged CV metadata clears the live filename/blob key so the older UI does not present a removed CV as a normal downloadable upload.

Purged CV files
CV blobs deleted by the v0.16.1 archive action are not recreated by application rollback. If those files are required after archiving, they must be supplied again by the client/adviser.
