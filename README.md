THiS CRM v0.17.92 — Pathway-specific intake approval invitations

USING THE FEATURE
In Enquiries > Intake, open an assessment and choose Recommended pathway. Options cover SMC, Green List, partnership, dependent children, other family, investor/business, work, visitor, student and other/discuss at consultation. Existing free-text pathway values remain selectable and use neutral introductory wording.
Assign an adviser with a valid email address, then choose Send approval + booking link. Review and edit the subject and message before selecting Send approval email and confirming the CRM prompt. The preview explains that the secure booking button and adviser contact details are added at send time. Cancelling the preview sends nothing. Changing the selected pathway, adviser or recipient clears the preview so the next preview matches the current assessment.
The message invites the applicant to consultation and describes the relevant subjects for that pathway; it does not confirm visa eligibility or an application outcome. The new pathway preview replaces the generic approval wording for this workflow. Existing editable global email templates are not rewritten; decline emails and legacy approval calls retain their previous behaviour. Per-email edits are recorded in the sent email log, not saved as master templates. The reviewed body does not inherit the old generic skilled-migrant paragraphs or fixed consultation pricing; booking options remain managed by the existing booking system.
The recommended pathway is saved with the assessment through Save changes, or together with the assigned adviser before sending the new approval invitation. This send action does not save other unsaved assessment fields. Booking link generation, Microsoft delivery, assigned-adviser CC and email logging reuse the existing system. No live email was sent during development.
