# THiS CRM v0.17.78

THiS CRM v0.17.78 — 7 November 2026

PUBLIC FORM STYLE REFRESH
Based on v0.17.77. Contact, Investor contact, guided full assessment/intake and employer questionnaire now use the refreshed website's Montserrat typography, dark green #042D2D, soft mint #DFF6ED, white cards, restrained borders and warmer standalone background. Public iframe backgrounds remain transparent. Controls have consistent 48px minimum field/button heights, 16px entered text, readable labels, clear keyboard focus, mint primary actions and quieter secondary buttons. Cards/sections, guide panels, progress tabs, errors, success states and action bars share the same visual language. Rounded corners/shadows/gradients have been simplified. Unselected goal choices remain readable rather than faded.

Employer contact/business fields use two columns where space allows and stack on small screens. Employer section fade-in is disabled so fields are immediately clear. The three public form shells carry an explicit website-form-refresh class. New CSS is scoped to that class, with only private font-face declarations and body rules conditional on its presence. This keeps CRM workspace, Studio, agreement/PDF output, booking, seminar and feedback styling out of scope. Embedded forms remove inherited mobile CRM bottom padding; existing resize-message types, source/origin checks and submission flows are retained.

Fonts are self-hosted using the same Montserrat files from the user's website refresh assets. Four weights and their OFL licence are included under public/fonts/website and the font files are precached. No external font provider, extra tracking or new dependency is introduced.

VISA QUICK CHECK
The live Visa Quick Check at /contact/visa-quick-check is an inline Squarespace widget, not a CRM route. SQUARESPACE-QUICK-CHECK-STYLE.html supplies a page-scoped CSS-only addition for its observed #this-smc-quick-check root and sr/vp classes. It applies the same typography, fields, primary/secondary controls, cards, choice states, progress, spacing and focus treatment. Container queries stack controls inside narrow Squarespace columns even on a wide desktop. Warning and error treatments remain distinct; original hidden/active screen states are retained. Entry/section fade animations are suppressed within the widget so it is immediately readable.

Keep the original checker HTML, JavaScript, occupation data, branching and results. The supplied style snippet contains no JavaScript and changes no policy logic, answers, submission or assessment links. It does not change Squarespace grid rows, section sizing, icons or unrelated page elements. Append it after the existing checker code in the same HTML Code block, or use that page's Header Code Injection. See FORMS-REFRESH-INSTALL.txt. CRM deployment alone does not restyle the inline Squarespace checker.
