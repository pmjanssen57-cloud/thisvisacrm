# THiS CRM v0.17.31 - Studio Preset Reordering

Built from v0.17.30.

## Changes
- Agreement Studio: scope-of-services rows can be moved Up / Down without rewriting them.
- Agreement Studio: professional fee stages can be moved Up / Down and are automatically renumbered in the preview/output.
- Agreement Studio: government fee rows can also be moved Up / Down for consistency.
- Instructions Studio: advisers can move included preset sections Up / Down on the client copy without altering the published master template.
- Existing Road Map section-order controls remain unchanged.
- Reordered items are stored in the existing structured studio state and therefore persist with the draft.
- PWA shell cache advances to v0.17.31.

## Database
No schema change. Database remains at 45 migrations.
Historical/applied migrations are unchanged.
