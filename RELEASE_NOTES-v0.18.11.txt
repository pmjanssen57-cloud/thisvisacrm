THiS CRM v0.18.11 – Instructions Studio startup hotfix
23 November 2026

BASELINE: v0.18.10 (Blank Instructions Builder; retains v0.18.09 Delegated Tasks).

ISSUE:
After deployment of v0.18.10, Instructions Studio could fail to initialise while creating/opening ordinary instructions. The generic 15-second load guard reported the document could not finish loading, even when the user's saved draft was intact.

ROOT CAUSE:
The legacy v0.15.6 template synchroniser iterated across every instruction pack, including the new 'blank' pack. It assumed each pack has a Road Map and attempted to compact blank.docs.roadmap (undefined), which raises a JavaScript TypeError before the Studio finishes initialising. The error affects standard guides as well because this synchroniser runs globally at startup.

FIX:
- Skip legacy Road Map template synchronisation for packs that do not contain a Road Map, preserving the independent blank guide and existing named master workflow.
- Bump the Instructions Studio script URL to v0.18.11 so clients retrieve the corrected code.
- No data model, database migration, existing draft, or content changes.

VERIFICATION:
- JavaScript syntax validation passed.
- Regression test confirms normal packs synchronise, while blank packs with no Road Map bypass the legacy conversion and retain their guide.
- Deployment ZIP integrity verified.
- Full Vite build and deployed Netlify browser/integration tests not completed; container Chromium browser navigation is blocked by environment policy.

DEPLOYMENT:
Deploy v0.18.11 to a Netlify deploy preview, then check an existing standard Skilled Migrant instructions draft, creation of a new standard draft, creation of a blank guide, its preview and save/reopen. If problems continue, inspect the browser JavaScript console for the first error.

ROLLBACK:
THiS-CRM-v0.18.09.zip (last release before the v0.18.10 regression; blank guide feature not present).
