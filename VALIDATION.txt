THiS CRM v0.18.18 — validation

25 CRM tests passed on Node 20.19.0 using isolated PGlite PostgreSQL. Tests cover
administrator permissions, first-use schema, concurrent revision saves, atomic
history, safe public fields, strict dates and URLs, repeatable imports, encrypted
pairing, saved snapshots, interrupted deliveries, reconciliation, retry identity,
unpublish, restore, disconnect and missing-secret recovery.

18 Site tests passed using SQLite with the real D1 migration and Web Crypto.
They cover signatures and timestamps, rendering, duplicate/stale/conflicting
events, tombstones, the feed and search index, owner pairing, CSRF, single-use
approval and revoked connections.

The CRM production build, complete server bundle and PWA/cache checks passed.
The existing large-bundle advisory remains. Isolated browser checks covered new
drafts, preview, publication, saving a later draft without changing the published
page, and desktop/mobile layouts.

Package verification checks baseline preservation, ZIP integrity and safe paths.
SHA256SUMS.txt and verification-report.json accompany the release.

Limits: no production CRM publication, live client writes, physical mobile device
checks or cross-browser suite. Real owner pairing requires the deployed CRM.
Existing Squarespace presentation dependencies remain in the mirror.
