THiS CRM v0.17.73 — 4 November 2026

Based on v0.17.72. Restores the live Instructions Studio preview and corrects cover-page fragmentation in PDF output.

LIVE PREVIEW
Edit & preview is now the default on desktop at 1180px and wider, including opening an existing instruction draft from the CRM. The editor and preview occupy two explicit columns, with the preview kept alongside the editor as the page scrolls. The preview panel stacks its toolbar, note and document vertically and has its own scroll area. This corrects inherited layout rules that could squeeze the editor/preview into old grid columns. Smaller screens open in the editing view with Preview one click away; Edit & preview remains available as a stacked view.

Selecting an editing block brings that section into the live preview. Updates retain the preview scroll position rather than returning to the cover on every edit. Header & introduction returns to the cover. The preview note reflects the new block-building workflow. The v0.17.72 client-name/category setup, optional family block, document/person assignments and rich block editing remain in place.

PDF COVER FIX
A dedicated Instructions-only stylesheet gives the cover three bounded grid regions for the heading, image and footer, replacing its flexible vertical layout. The regions fit a single A4 page and retain the prepared-for/date and website footer inside that cover. Cover child minimum heights and inherited flex sizes can no longer push the footer onto a separate page. Preview and print use the same A4 canvas width and bounded cover geometry. Existing content blocks, wording, person mappings and renderer pagination logic are unchanged.
