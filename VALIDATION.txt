LIMITS
No production deployment or live Identity, Microsoft 365 email, external integrations,
remote database migration or real client data exercised. Browser responses were mocked for
UI tests; backend behaviour checked separately in local PostgreSQL. PDF used headless Edge;
physical/browser print dialogs may paginate differently. Mobile checks used resized desktop
Edge viewports, not physical iOS/Android devices. Node 24 was available locally; deployment
continues to pin Node 20.19. Existing large-bundle Vite advisory remains. This release changes
UI only; validation is representative rather than exhaustive for every historical workflow.
