THiS CRM v0.17.69 — 2 November 2026

Based on v0.17.68. My Work now has a dedicated Find a client to update search above its date filters. Search by name, email or company and select a result to open the existing Update matter panel on the same page. Results show the client/matter, main adviser, next action and exact action or review date, including an explicit No date set state. Waiting matters use the review date, matching the daily queue's scheduling rules.

Search uses the active individual and commercial records already available to the signed-in CRM session. It searches across adviser/date views, so future-dated matters and other advisers' loaded clients can be found without changing the selected My Work responsibility or range. Closed clients remain in the existing full Clients tools and are excluded from this active-client lookup. No new data fetch or server access permission is added. Multi-word name searches work in either name order and ignore accents. Matching also includes email, company/NZBN, phone and case/matter names. Results are shown ten at a time with Show more clients. Clear search and Escape reset the lookup. Normal keyboard navigation opens results using their existing update actions.

The lookup does not filter or change the daily action queue, personal tasks, date reminders or their badge counts. Saved action/date changes refresh the result while preserving the query. Updating an in-scope matter to today moves it into the due queue as usual; another adviser's matter remains outside the current responsibility view. Save failure keeps the draft in the update panel for retry. Individual and commercial updates use their existing save routes. Existing unsaved-change safeguards, pinned notes, history, portal wording, client editing and employer questionnaire improvements remain intact.

No schema change or new migration. All 48 migration files and all 24 Netlify function modules are byte-identical to v0.17.68. Public JavaScript, Studio engines and document generation code are unchanged. PWA/cache version updated. Nothing deployed to production.
