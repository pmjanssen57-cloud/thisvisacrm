THiS CRM v0.17.70 — 2 November 2026

Based on v0.17.69. The public seminar registration form is more compact and adapts to its available width. Outer padding, section gaps, headings, consent cards and controls are tightened. Fields use two columns in wider containers and one column at 560px or narrower. The two background note fields share a row when space permits. Controls retain 44px minimum touch height and 16px entry text. Notes start shorter and grow with their content instead of adding an inner textarea scrollbar.

The seminar route now measures its content and sends height-only updates to the embedding page. Measurements use the actual shell/card, not document scrollHeight or viewport-based minimum height, avoiding iframe growth loops. Loading, active form, validation/error, thank-you and no-seminar states are measured. ResizeObserver, width changes, font readiness and an explicit parent request support remeasurement. Observer/listener cleanup is included.

A new turner-hopkins-seminar-registration-embed.html snippet fills its containing block width and adjusts iframe height to the form content. It checks both exact sender origin and iframe window, expected message type/source and a finite bounded numeric height. Height messages contain only type, source and height, never field values. Default public iframe path remains /seminar. Existing required fields, consent, GET/POST payload, CRM registration flow and conversion reporting are unchanged.

INSTALLATION ORDER
1. Deploy this v0.17.70 source release using the normal Netlify build.
2. Replace the existing seminar iframe Code block in Squarespace with the complete new embed snippet (provided separately as a paste-ready .txt file). Select HTML mode with Display Source off. Keep one embed per intended form location.
3. Save and check the public page on desktop and mobile.

Both steps are needed: the old seminar form does not emit the new sizing message. The form uses the width assigned to the Code block and expands naturally in height. It cannot display all fields inside an arbitrarily short fixed-height box while also avoiding scrolling. The replacement removes iframe scrolling by growing the iframe; normal website-page scrolling remains. It does not move or resize neighbouring Squarespace Fluid Engine blocks. If Squarespace reserves blank section rows after the iframe shrinks, adjust that section's layout/height separately; do not apply the earlier guide-section CSS to the seminar section.
