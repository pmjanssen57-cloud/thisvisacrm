THiS CRM v0.17.65 — 27 October 2026

My Work now brings three distinct work lists together: Client actions, Personal tasks and Date reminders. The sidebar badge is the sum of due client actions/reviews, due personal tasks and actionable date reminders. The three header counts explain the total. Personal tasks are separate from a client's next action; adding or completing a task does not replace that next action. Existing Today & overdue, Next 7 days, All work, Needs action/date and adviser scope controls remain available. Date reminders appear inside the existing warning windows, so an upcoming visa date can need attention before its actual expiry. Commercial matters remain in the client-action list; specialist employer compliance reminders remain in the existing commercial tools.

Tasks can be added, edited, linked to an individual client, completed, snoozed or silenced from My Work. The task panel has title, date, adviser, client and notes, with one Save task action. Snooze moves the task's due date to the chosen future date. Completed and Silenced tasks are retained and can be restored. Future Open tasks are available in Next 7 days or All work. Save failures retain edited task fields and show an inline error. Unsaved task changes use the CRM discard confirmation. The existing Personal tasks area remains available and understands Silenced status.

Date reminders have Complete, Snooze and Silence controls, plus a direct Open record shortcut. These actions retain the actual dates. Snoozed reminders return when their review date arrives. A per-client Silence document expiries action can quiet the client's dated, applicable document reminders in one CRM-confirmed action; visa, PPI, filing and other key dates are not included in that bulk operation. The daily update snapshot also has a document-expiry silence shortcut. Dates are never automatically silenced because a visa has been lodged. Completed/silenced/future reminders can be inspected and, where applicable, restored. Reminder changes are recorded in internal activity history.

The daily update snapshot now uses Stages & documents and Client details as distinct shortcuts. The full workspace is labelled Client record. Stages & documents covers application progress and evidence checklists; Client details holds editable personal, contact, family and matter fields. Tabs retain one shared draft and one Save changes bar. The pin and action-history popup from v0.17.64 remain available. Existing stage/document selectors, labels, aligned action bars, responsive field grids and saved/error states were checked alongside the new task/reminder cards. Mobile quick actions wrap into two columns and task fields stack on narrow screens, with reachable panel save controls.

SCHEMA / MIGRATIONS
No schema change. No new migration. All 48 migration files are byte-identical to v0.17.64. Personal task Silenced uses the existing unconstrained TEXT status column. The only changed Netlify module is crm.mjs, limited to personal-task status normalisation and database mapping so Silenced survives a reload. Other 23 function modules are byte-identical. Prior pin retention logic is unchanged. Document reminder status and review dates use existing fields.

LIMITS
Local Edge with synthetic records and intercepted APIs. No production database, real email or physical-device testing. Database persistence logic was checked with SQL stubs and browser response/reload fixtures, not a live database. Concurrent adviser writes were not exercised. Representative layouts and conditional flows are covered, not every possible record length/path. Commercial compliance tools were not redesigned into the new date-reminder list. Local Node 24; Netlify pins Node 20.19. Existing bundle-size advisory remains.

DEPLOY / ROLLBACK
Deployable source ZIP uses the normal Netlify build (yarn build, publish dist); node_modules and generated dist are excluded. The rollback ZIP is an exact v0.17.64 release copy. No schema rollback is required. A rollback retains stored task data, but v0.17.64 does not understand Silenced and will display those tasks as Open; review them after rolling back. Existing date reminder statuses remain compatible, although the older UI does not have the new snooze-return behavior. Nothing deployed to production.
