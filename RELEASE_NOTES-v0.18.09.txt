THiS CRM v0.18.09 – Delegated Client Tasks
20 November 2026

SOURCE: v0.18.08 deployment package. Includes all existing features from that version.

Changes
- Adds a Delegated / Assign to colleague task type in My Work > Add task.
- Uses the existing personal_tasks table, adding two new nullable/default columns: delegated and assigned_by_id. Existing personal task rows remain personal reminders with Open/Completed/Silenced lifecycle.
- A delegated task links to an existing individual client, names the assigning adviser and assigned colleague, and has a due date, task, notes and status Assigned / In Progress / Completed.
- The assignee and assigner can both view progress via My Work. Added filters for Assigned to me and Assigned by me, with named ownership and quick Start/Complete/Reopen controls.
- Delegated work counts as active My Work until completed and is shown in the existing Tasks screen.
- Backend assigns the actual logged-in adviser as task creator, protects the creator identity, limits non-admin updates to the two involved advisers, and restricts task deletion to the creator/admin. Assigned colleagues can update status and progress notes; the assigning adviser can change other fields.
- Email notifications via Microsoft Graph on assignment/reassignment and on status changes. Each attempt is tracked in email_notifications; successful task saves are retained even if email fails. Notifications are not resent for unchanged statuses.
- Notification goes to the assigned colleague on a new assignment, or to the other involved adviser when progress is changed. Uses configured team adviser email address.

Important limitations
- The new task type currently links to individual client records (not separately stored commercial-company matter records).
- Email notifications require a correctly configured Microsoft 365 integration and adviser email addresses. No daily automatic email digest or deadline reminder job was added; tasks appear in My Work when due.
- My Work is the supported editor for creating/delegating tasks. The older Personal Tasks centre continues to support ordinary reminders.
- Database columns are added via additive, idempotent ALTER TABLE statements in existing schema bootstrap; no existing columns/data are deleted.
