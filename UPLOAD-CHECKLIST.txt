THiS CRM v0.18.19 — upload checklist

1. Extract THiS-CRM-v0.18.19.zip.
2. Upload all extracted contents to the existing thisvisacrm GitHub repository,
   replacing matching files. Preserve folders and existing deployment settings.
3. Confirm package.json, yarn.lock and netlify.toml are together at the root.
   Do not upload just dist, the ZIP itself, or an enclosing release folder.
4. Let Netlify deploy using its existing yarn build and dist settings.
5. Confirm dependency installation passes and the deployment is Published.
6. Refresh the CRM. Website Studio setup remains as described in its guide.

No Node version change, ignored engine checks, new environment secret, database
reset or rollback of client data is needed for this dependency installation fix.
