THiS CRM v0.18.20 — Upload checklist

1. Extract THiS-CRM-v0.18.20.zip and upload its complete contents to the existing
   thisvisacrm GitHub repository, replacing matching files.
2. Keep package.json, yarn.lock and netlify.toml at the repository root.
3. Allow the existing Netlify build to finish successfully, then refresh the CRM.
4. Open Website > Import existing news. Nothing should start selected.
5. Search for an article, tick it, and choose Import selected.
6. Confirm only the chosen article appears in Website Studio. Reopen the picker;
   it should be marked Already in Website Studio and unavailable for reimport.
7. Your current website connection should still show Website connected.

No migration, environment change or reconnection is needed. Older cached CRM
screens must refresh to use the explicit-selection import operation.
