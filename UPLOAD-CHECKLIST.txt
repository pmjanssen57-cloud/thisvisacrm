THiS CRM v0.18.18 — deployment checklist

1. Confirm GitHub has not advanced beyond the recorded v0.18.17 baseline.
   Merge into newer source first if necessary.
2. Upload the complete package to the existing thisvisacrm GitHub repository,
   preserving netlify/, public/ and existing Netlify settings.
3. Build with Node 20.19.0, yarn build, publish directory dist.
4. Refresh the CRM. Website should appear for administrators only.
5. Open Website. Its four tables initialize on first use. Connect the private
   mirror as its owner; confirm Website connected back in the CRM.
6. Import existing news. Repeating the import must preserve saved edits.
7. Save and preview a draft. Publish reviewed content and confirm Accepted.
   Verify that a later draft does not alter the published page.
8. Inspect the news index and homepage feed. Unpublish any temporary test article.
   Keep the Site owner-private.
9. Read the guide before handling interrupted publication or restoring backups.
10. Check existing navigation and routine CRM workflows after deployment.

The package does not pair or publish production content automatically. Changes to
Squarespace, the public domain, enquiries and email delivery are outside this release.
