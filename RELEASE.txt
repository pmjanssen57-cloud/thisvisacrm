THiS CRM v0.17.4 - My Work Adviser Role Filter

Baseline
- Built directly from v0.17.3 My Work Focus & Board Guidance.
- Retains the Matter Workspace architecture, visual polish, configurable notification recipients, archive/storage cleanup, assessment reliability fixes and Agreement Studio print fixes.

My Work ownership filtering
- My Work now defaults to Main adviser files when a specific adviser is selected in the global View menu.
- Adds three clear ownership views: Main adviser files, Backup adviser files, and All files.
- Main adviser shows only matters where the selected adviser is the primary adviser.
- Backup adviser shows only matters where the selected adviser is the backup adviser and not also the primary adviser.
- All files combines both roles for the selected adviser.
- When the global View is set to All advisers, My Work defaults to All practice files.
- Ownership counts respond to the selected date range, so advisers can see how many primary, backup and combined files fall into Today, Next 7 days, Next 30 days or All scheduled.
- My Work metrics, quiet prompts and suggested next file now follow the ownership selection rather than mixing primary and backup responsibility.
- In All files mode, cards show a small Main adviser file / Backup adviser file badge so ownership is obvious at a glance.

Database and deployment
- No database migration.
- All existing migration files remain unchanged from v0.17.3.
- No new environment variable or dependency.
