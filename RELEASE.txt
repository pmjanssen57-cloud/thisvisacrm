v0.13.54 - Approved Seminar Registration Export

Changes
- Adds an Export approved control to the Seminar Registrations workspace.
- Exports only registrations with Approved status from the currently selected seminar view.
- When All seminars is selected, approved registrations from all seminars are included.
- Downloads an Excel-compatible UTF-8 CSV with seminar details, registrant information, approval dates and reviewer information.
- The export count is shown on the button and the control is disabled when there are no approved registrations.
- Existing registration approval, decline, status and email workflows are unchanged.

Technical
- No database migration.
- No new dependency.
- Advances package, service-worker cache and backup source version to v0.13.54.
