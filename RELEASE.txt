THiS CRM v0.17.52 — Intake review layout fix
20 October 2026. Baseline: v0.17.51.

FIX
After emailing intake results, the review panel previously squeezed review flags,
action buttons and the confirmation into a single horizontal flex row. The confirmation
reduced the buttons to a narrow vertical stack with excessive text wrapping.

The panel now separates these into full-width rows: review flags/related records,
a responsive action grid, then the confirmation or error. Buttons use two readable
columns where space permits and one column on phones. Icons keep their width and long
email addresses wrap inside the message. Status/error messages are announced accessibly.
The existing footer, email confirmation/send handlers, CV downloads, approval/decline
actions, client conversion and save controls are preserved.
