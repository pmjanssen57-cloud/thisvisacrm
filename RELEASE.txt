THiS CRM v0.16.0 - HuB Visual Refresh

Baseline
- Built directly from v0.15.16 Migration Integrity Restoration.
- v0.15.16 remains the rollback baseline and is not modified by this package.
- Retains the full v0.15.16 CRM, family editor fix, database-idle optimisations, native live chat, enquiries/intake, booking, client portal, commercial compliance, Instructions Studio, Agreement Studio, adviser personalisation and backup functionality.

Visual refresh
- Introduces a HuB-inspired staff CRM application shell with a persistent dark-teal left navigation rail on desktop.
- Moves primary staff navigation into the left rail: Dashboard, My Day, Tasks, Clients, Enquiries & Intake, Studio, Commercial, Billing, Bookings, Calendar and Resources.
- Adds direct Tools, Help & Guide, Adviser and Admin/Backup navigation in the lower rail where permissions allow.
- Reworks the staff top bar around global client search, local time/weather, compact operational actions, the New menu and adviser identity.
- Keeps the existing mobile bottom navigation and mobile tool flows.
- Introduces a mint/teal dashboard hero treatment, refined KPI cards, softer operational cards, modern status pills, cleaner filters, improved card hierarchy and consistent compact application spacing.
- Restyles client records, commercial records, enquiries/intake, booking, calendar, billing, task, Studio, resource and administrative surfaces to use the same visual system while retaining dense operational layouts where useful.
- Instructions Studio and Agreement Studio retain their existing editors and workflows; their overlay now aligns with the desktop CRM sidebar.
- Public assessment/contact/seminar forms, client portal, employer portal, public booking flow and public live-chat experience are intentionally not converted to the staff CRM shell.

Rollback safety
- No historical database migration was edited.
- No new database migration is included.
- No database schema or data transformation is required.
- No new dependency or environment variable is required.
- The original v0.15.16 ZIP is the immediate rollback package if the visual refresh is not retained.

Cache/versioning
- Package version and staff asset cache-busting references updated to v0.16.0.
- PWA shell cache name updated so existing installations receive the refreshed interface.
