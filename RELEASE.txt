THiS CRM v0.17.76 — 6 November 2026

INSTRUCTIONS STUDIO: INDIVIDUAL ELEMENTS
Based on v0.17.75. Whole-section duplication remains available. Individual timeline steps, strategy/test cards and callouts now have an Elements & layout panel above the full wording editor. Select an element, duplicate it, move it up/down within its group, remove it with CRM confirmation, or add a new step/card/callout. Step/card numbering is recalculated after structural changes. Nested elements remain part of the existing block HTML, so no template conversion or database migration is needed.

Each element can have its heading and first paragraph edited separately; timeline steps also expose a time estimate. Additional paragraphs, links, tables and rich wording remain editable through the existing complete block editor below. The first-paragraph field deliberately edits plain text only; it does not replace other paragraphs. Visual controls provide original/soft/outlined/minimal surfaces; original/deep teal/mint/neutral accents; number visibility; original/one/two-column card arrangement; and original/compact/roomy group spacing. Timeline spacing is carried onto each item so the existing timeline pagination preserves it. Controlled class names are retained by the existing safe-HTML filtering. Duplicate elements have HTML IDs cleared to avoid duplicate DOM identifiers.

The new controls sit above the complete wording editor so advisers can reach them without scrolling through every existing step. Layouts wrap and stack at narrow widths. The original full-section controls, person-specific evidence assignments, family sections, stock library, custom sections and rich-text tools remain available.

ADVISER SIGN-OFF
A dedicated Adviser sign-off item in the outline edits the closing line, adviser name, role, optional licence, organisation, optional contact line, visibility and simple/soft-card/accent-line presentation. It applies to the instruction pack. Name/licence use the existing client fields; the other preferences are saved in builder76Signoff alongside the existing draft state. Blank licence details no longer print a trailing hyphen; when the adviser name is empty, the organisation provides a clean team closing. The old double-rule/empty-name appearance is replaced with a compact closing. The sign-off can be hidden.

The live preview follows the sign-off selection. A closing-only last page is checked against the previous page using measured geometry; it is merged where it fits. When it does not fit, a preceding content section is moved with the closing where feasible. This avoids a sign-off alone on its own page in the verified examples. Sign-off and element presentation are also applied inside the hidden pagination measurement area, so the live preview and PDF use the same appearance. Changes can legitimately increase page count, particularly stacking a whole group of cards into one column.

SAVING / OUTPUT
Element changes use the existing saved HTML model. New sign-off metadata is included in the existing JSON draft; forced CRM-style save/reopen checks retain it. Live preview remains beside the editor on desktop and accessible as a separate view on mobile. The bounded A4 cover fix is retained. Existing draft wording, people mappings and document requests remain; printed sign-off presentation intentionally changes. The core Instructions renderer and people engine files are byte-identical; behavior is extended in the builder wrapper/styles. Agreement output and builder are unchanged.

SCHEMA
