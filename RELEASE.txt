THiS CRM v0.17.43 - Modular Instructions Studio Pilot

Changes
- Reframes Instructions Studio around a modular guide builder while preserving the existing PDF/output design.
- Existing visa packs are now labelled as starting points rather than rigid template packs.
- Adds a reusable guidance library with Suggested, Common, Relationship, Work, Residence, Financial and Special situations categories.
- Advisers can add library sections to an individual client draft without changing the master template.
- Advisers can add fully client-specific custom sections for unusual cases.
- Every section can be tailored through a plain document-style editor and restored to its starting wording where applicable.
- Existing sections, library sections and client-specific sections are visibly identified.
- Existing section reordering and inclusion controls remain available.
- New library wording uses a softer, more supportive Turner Hopkins style with What we need from you / Why this helps / Helpful tip patterns.
- Road Map authoring has been softened and gains the same Add from library / Add custom section controls.
- Existing template governance, client data, PDF arrangement, CRM save/ready workflow, mobile single-scroll behaviour and output renderer are preserved.
- No database migration.
