THiS CRM v0.17.5 - My Work Quick Move

Baseline
- Built directly from v0.17.4 My Work Adviser Role Filter.
- Retains all v0.17.4 functionality and visual treatment.

My Work Quick Move
- Adds a Move control to every My Work matter card alongside Open matter.
- Move provides direct access to the four operating states: Needs my attention, Waiting on client, Waiting on INZ, and Ready to progress.
- Simple moves save immediately when the existing next action/review information is sufficient.
- If required information is missing, a compact Quick Move dialog asks only for the minimum needed to keep the matter safe in the workflow.
- Waiting on INZ requires a review date so the matter returns to My Work.
- Matters with no next action cannot be moved into an active/client state without a short next action.
- Existing next-action and date information is preserved wherever possible when moving between states.
- Quick Move does not alter the visa stage, portal wording or client communications.
- Each move writes an automatic matter timeline entry showing the previous and new board state.
- The How cards move panel now explains the difference between Quick Move and the full Update File workflow.

Database and deployment
- No database migration.
- All 43 existing migration files remain unchanged from v0.17.4.
- No new environment variable or dependency.
