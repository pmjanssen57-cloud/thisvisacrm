THiS CRM v0.17.53 — Clear document and stage controls
22 October 2026. Baseline: confirmed v0.17.52.

DOCUMENTS
- Replace the ambiguous inclusion/obtained checkboxes with separate labelled choices:
  Needed for this application: Required / Not required.
  Document status: Outstanding / Received.
- Required and received remain separate states; not-required documents cannot be marked
  received. Marking a document not required clears the received state as before.
- A document marked not required stays visible for review by showing not-required items;
  the existing Hide not required control can collapse them again.
- Expiry date and Expiry follow-up are labelled independently. The latter uses Show on
  dashboard / Do not show on dashboard, with the existing date-follow-up mapping.
- The remaining selection checkboxes are explicitly Select for bulk update. Bulk actions
  are Mark received / Mark outstanding and apply only to currently required selections.
- Custom document naming, addition/removal, dates and explicit Save behaviour are retained.

STAGES
- Replace overlapping Applies/Completed checkboxes with labelled applicability and
  progress choices. Optional/custom stages offer Yes - include stage / No - not applicable.
- Core stages show Required stage and an always-included explanation.
- Progress offers Not completed / Completed, or disabled Not applicable when excluded.
- Completion date appears only when a stage is completed. Existing completion behaviour
  is preserved: marking completed supplies today's date if blank; undoing completion or
  excluding a stage clears the completion/date. Existing saved dates are retained.
- Reordering buttons are clearly separated and named for keyboard/screen-reader users.
  Remove is offered only for custom stages. Custom naming and explicit Save remain.

LAYOUT / PRESERVATION
Each item is a readable card with a distinct name/header and labelled controls. Desktop
document fields use two columns; phone controls stack with readable type and touch targets.
The replacement card layout avoids the legacy overlapping grid areas and narrow labels.
No stage definitions, progress rules, document identifiers, ownership or persistence model
change. Portal and document output engines remain unchanged.
Includes v0.17.52 intake-email layout fixes and v0.17.51 people-first Instructions Studio.
