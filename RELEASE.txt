THiS CRM v0.17.16 - CRM Startup Load Stabilisation

Built from v0.17.15.

Fixes
- Prevents a stale/failed CRM load request from overwriting the result of a newer successful request.
- Clears the CRM load error immediately after the latest successful load.
- Adds one short automatic retry for transient network or 5xx startup failures.
- The empty-database screen is now shown only after a confirmed successful CRM response containing no records.
- A load error no longer masquerades as an empty database.
- Existing CRM data remains visible if a later refresh fails.
- Adds a Retry button to the CRM load error banner.

No database migration or schema change.
