THiS CRM v0.17.41 - Mobile Single-Scroll Reliability

Changes
- Mobile scrolling is normalised across the CRM so standard pages use the browser/document as the single vertical scroll owner.
- Desktop max-height and nested overflow panes are removed on mobile for common lists, dashboards, workload queues, client/commercial lists and email/template lists.
- Fixed modals, drawers, bottom sheets, client details, live chat and My Day retain exactly one deliberate internal vertical scroller.
- Instructions Studio Pack/Edit/Preview now scroll as one mobile document rather than nested panel + preview scrollers.
- Agreement Studio Sections/Edit/Preview uses the same one-scroll model.
- Horizontal tabs remain swipeable without blocking vertical page gestures.
- Mobile drawers use dynamic viewport height (100dvh).
- Desktop behaviour is unchanged.
- No database migration.
