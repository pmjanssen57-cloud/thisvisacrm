v0.13.57.6 - Agreement Pagination and Section Flow Polish

This maintenance release keeps the working v0.13.57.5 CRM and Studio integration and tightens the Agreement document layout.

- Agreement sections now use the remaining space on the current A4 page before a new page is created.
- Long agreement sections can continue naturally onto the next page instead of forcing the complete section onto a fresh page.
- Continuation pages use a restrained continued heading where needed.
- A light divider separates completed sections when they share a page.
- Direct preview editing continues to write fragmented body content back to the complete underlying section.
- The same pagination is used in the CRM authoring preview, print/PDF output and secure client agreement view.
- The service-worker and embedded Studio cache versions advance to v0.13.57.6.

No database, migration, dependency or API changes are included.
