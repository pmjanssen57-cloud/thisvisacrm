v0.14.2 - Live Chat Attention and Website Launcher Refresh

- Added a lightweight staff-attention endpoint for reliable waiting and unread chat counts without repeatedly loading the full chat workspace.
- CRM header attention checks now run every 10 seconds while visible, immediately on focus, visibility return and network reconnection, and at a reduced interval while hidden.
- Full chat conversations continue to refresh more frequently while the Live Chat drawer is open.
- Added stale-response protection so a delayed older request cannot overwrite newer chat counts or remove a newly displayed badge.
- The CRM chat badge now animates when its count changes and retains the highlighted header treatment while attention is required.
- Refreshed the public website launcher with a stronger THiS-aligned teal and mint treatment, an elevated icon medallion, a restrained outer halo and clearer depth.
- The website launcher now checks opening status and displays either Online now or Leave a message without requiring the visitor to open the panel.
- Preserved the floating desktop overlay and full-screen mobile chat behaviour.
- Updated service-worker and embedded asset versions so the revised badge and launcher are fetched after deployment.
- No database migration, dependency change or additional subscription is required.
