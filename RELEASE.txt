THiS CRM v0.17.49 — Employer questionnaire review
Built from completed v0.17.48. 20 October 2026.

REVIEW WORKFLOW
Employer questionnaires now use the intake-style review treatment:
- Structured queue cards with adviser, review status, accreditation and submission details.
- New / In review / Reviewed filters, separate from Submitted / Processed / linked views.
- The same wide review panel and persistent Cancel, Save & next, Save changes footer.
- Assessment triage: review status, assigned adviser, consultation/outcome and notes.
- Save review independently without creating or attaching a commercial client.
- Failed saves retain edits; dirty close protection; optimistic revision checks prevent
  another adviser's saved review being silently overwritten. Refresh/reload allows recovery.
- Attach/Create actions and possible NZBN/business/email matches remain separate and clear.
  Local review changes are saved before linking. A newly created commercial client takes
  the saved assigned adviser; attaching retains the existing client's ownership.
- Original submitted answers remain unchanged and appear in grouped, readable sections.
- Supporting files are downloadable from the answer/document view. Related submissions,
  recorded duplicate warnings and separate draft/in-progress visibility are preserved.

PRINT / SAVE PDF / DOWNLOAD
- Print / save PDF opens a branded report using the browser's print/Save as PDF workflow,
  consistent with individual intake questionnaires.
- The report includes the employer answers, key people, declarations, document register,
  review notes, assigned adviser and submission/link status.
- It uses the current review; unsaved changes are explicitly labelled in the report.
- Download questionnaire saves a self-contained printable HTML copy, with the actual THiS
  logo embedded. It is labelled as a questionnaire download, not a direct PDF download.
- A blocked print window falls back to a printable HTML download with a visible explanation.
- Supporting document names are listed; original attachment bytes are downloaded separately.
- Resume tokens, stored blob paths and technical hashes are excluded from the report.
