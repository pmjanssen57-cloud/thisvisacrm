THiS CRM v0.17.90 — 12 November 2026

FIXES
Website chat now updates the conversation list while the window remains open. Attention/count polling no longer advances the separate conversation-list revision cursor before that list has been received. Initial loading, new arrivals and switching from Team to Website were tested.

Instructions Studio waits for the builder to finish loading before marking a saved document ready. Embedded CRM sessions use the selected saved record rather than unrelated browser workspace caches. Saved tailored text and custom guides are preserved, including supported older snapshot formats. Initialization retries and a clear Reload action replace a blank editor when loading fails. Save, print, publish and close-time snapshot saving are blocked until initialization succeeds, protecting the original draft from an empty failed load. Mobile loading/reload controls fit smaller screens.

No new migration, schema, dependency, environment or backend change from v0.17.89. All 52 existing migrations and 33 Netlify modules are byte-identical. Existing Team chat, seminar invitations/reminders, employer workflow and agreement signing safeguards are retained. Document wording, cover and print rendering remain unchanged by this fix.
