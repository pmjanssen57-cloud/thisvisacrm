THiS CRM v0.15.2 — Reliable Live Chat Schedule Loading

This release fixes the live chat settings window showing the default seven-day schedule after the CRM is reloaded.

Changes:
- Live chat settings are now fetched directly from the server before the settings window opens.
- Stored weekly hours are no longer inferred from an empty in-memory chat snapshot.
- Boolean schedule values are normalised safely, including legacy string values such as "false".
- The server verifies that weekly hours were persisted before reporting a successful save.
- Existing quick replies, opening-hours behaviour, adviser presence and chat polling are retained.

No database migration, dependency or environment-variable changes are required.
