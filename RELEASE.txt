THiS CRM v0.15.11 - Unified Client Editor + Agreement Hotfixes

Baseline
- Built from v0.15.10 Agreement Load and Print Flow Hotfix.
- Merges the v0.15.8 Unified Client Record Editor into the latest agreement-safe baseline.

Unified client record editor
- Added one Edit client record drawer from the client header and Client Overview.
- Personal details, contact information, matter/adviser allocation, family records, case strategy/internal notes and file references are edited in one place.
- Sections use accordion-style expansion with concise collapsed summaries.
- Changed sections are marked before save.
- Edits are held together and committed with one Save client action.
- Closing with unsaved changes provides discard protection.
- Overview summary panels open the same editor directly at the relevant section.
- Family and Notes & strategy are removed from the left client navigation because those details now belong to the unified client profile editor.
- Actions, Documents, Stages, Key dates, Billing, Instructions, Agreements and Portal remain separate operational workspaces.
- Closing/reopening a client remains a dedicated lifecycle action.

Agreement fixes retained
- Signed agreements refresh their current secure signatory records when opened.
- Accepted, partially signed and viewed status is visible in the Agreements workspace and Agreement Studio.
- Captured electronic signatures, typed names, email addresses and acceptance timestamps remain visible and printable.
- Accepted agreements remain locked against later edits.
- Opening one agreement fetches only that agreement and its signatory records rather than the entire CRM dataset.
- Agreement list refreshes use lightweight metadata and load large Studio snapshots only on demand.
- Agreement print flow retains the physical-page safety reserve and avoids the blank-page / section-gap behaviour corrected in v0.15.10.

No database migration, dependency or environment-variable changes.
