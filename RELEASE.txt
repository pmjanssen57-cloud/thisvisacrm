THiS CRM v0.17.28 - Safe Adviser Profile Deletion

Purpose
- Allow CRM administrators to permanently remove adviser profiles that were created in error and have no operational or historical CRM links.

What changed
- Adviser profile editing now includes a Delete adviser action.
- Deletion requires an explicit danger confirmation.
- Unsaved temporary adviser profiles can be discarded directly.
- Saved adviser deletion is performed server-side and remains restricted to CRM administrators.
- THiS blocks deletion when the adviser is linked to any client, commercial client, intake enquiry, agreement, task, calendar entry, consultation booking/configuration, live-chat conversation or notification recipient setting.
- Blocked deletion reports the linked record categories and counts so the administrator knows why the profile must remain inactive or be reassigned first.
- THiS prevents deletion of the adviser profile mapped to the administrator's current login.
- THiS also preserves the existing safeguard requiring at least one active Admin adviser.
- Adviser help text now explains the deletion safeguard.
- The PWA shell cache is advanced to v0.17.28.

What did not change
- No database schema changes.
- No new migration.
- All 44 existing migrations are byte-for-byte unchanged from v0.17.27.
- v0.17.27 Agreement PDF pagination hotfix remains in place.
- v0.17.26 public form conversion tracking remains in place.

Rollback
- Redeploy v0.17.27. No database rollback is required.
