THiS CRM v0.17.46 — Consistent workspace refresh
19 October 2026
Baseline: supplied v0.17.44, followed by the completed v0.17.45 questionnaire release.

STAGE 1 — ONE WORKSPACE
- Consistent neutral surfaces, forest-green actions, typography, spacing, borders and fields.
- One persistent sidebar and one main client/company/matter search.
- Removed duplicate top navigation/search controls and competing header shortcuts.
- My Work, Clients, Enquiries and Calendar are the primary destinations.
- Documents & templates, Billing and the existing practice reporting/overview sit below.
- Supporting tasks, bookings, resources and administration remain under More.
- Consistent side panels for updates, profile edits, enquiry reviews, document creation,
  commercial registers, tasks and appointment editing.
- Side panels manage focus, Escape, focus restoration and scrolling. Explicit dirty-state
  guards protect the matter/client editors. Existing enquiry close guards are retained.
- Session-only view/filter preferences and workspace scroll restoration; no CRM records or
  unsaved record content are written to this preference store.
- Matching mobile navigation, screens and full-width editing panels.
- Contextual help updated for the principal workflows.

STAGE 2 — EVERYDAY MATTER AND CLIENT WORK
- My Work defaults to a complete, scannable list, with Board retained as an alternative.
- Date and responsibility filters; waiting work and missing-action/date signals stay visible.
- Click a next action/pencil to update the matter without leaving the list.
- Individual and commercial updates share the same event/note/responsibility/action/date UI.
- Waiting states require a review date; save failures retain the entered changes for retry.
- Matter-stage and optional client-portal publishing controls are available where relevant.
- Client contact/personal/family information uses a focused edit panel.
- Detailed documents, actions, stages, key dates, billing and portal settings can be edited
  in the client record, rather than requiring another pop-out editor. Save returns to summary.
- Existing stage progression, client lifecycle, ownership and portal logic are retained.

STAGE 3 — ENQUIRIES, DOCUMENTS AND STUDIO
- Contact, individual intake and employer reviews use consistent side panels.
- Assessment triage stays visible; actions, communications and complete answers expand on demand.
- Intake Save & next saves before opening the next visible assessment.
- Existing archive/bulk archive, communications and conversion actions remain available.
- Employer matches/attach/create/history and duplicate visibility remain intact.
- Employer questionnaires are included in the main Enquiries attention count.
- Commercial documents have search plus expiry filters.
- Document checklists support selecting required evidence and marking it obtained/outstanding
  together; these edits are saved with the client record.
- Agreement/instruction lists have one New menu with the available source choices.
- Both embedded builders share styling, edit/split/preview modes and next-step navigation.
- Phones also have an explicit Sections view, retaining access to the section/guide list.
- Agreement sections have a formatted wording editor backed by the original builder state.
- Formatting respects the original disabled/read-only field locks.
- Template library/data export move under More; the original save controls retain their CRM
  message handlers. Save, issue and acceptance remain separate operations.
- A4 previews fit the available width. Printed content/page geometry match the baseline
  samples; print and client acceptance are not restyled by the editing chrome.

MIGRATION / SCHEMA
No new migration. No schema change from v0.17.45.
All 47 migrations are byte-for-byte unchanged, including migration 47 from v0.17.44.
A database older than v0.17.44 still requires the existing baseline migrations.
All 24 Netlify function modules are unchanged from v0.17.45.
No live database was connected or modified by this work.

DEPLOYMENT
This is a Netlify source release. Extract with package.json, App.jsx, main.jsx, netlify.toml,
public, src and netlify at the root, then use the existing Netlify build workflow.
Build: yarn build. Publish: dist. Functions: netlify/functions.
Keep existing environment variables and database/blob stores.
The ZIP intentionally excludes node_modules, local test harnesses and generated dist output.
A frontend-only static upload will not deploy the functions.
PWA cache: this-crm-shell-v0.17.46. The shared Studio assets are included in the precache.
No deployment has been performed as part of preparing this package.

ROLLBACK
THiS-CRM-v0.17.45-ROLLBACK.zip is byte-for-byte identical to the completed v0.17.45 ZIP.
Redeploy it with the same Netlify build workflow. No database rollback or migration deletion.
Questionnaires, linked clients, documents, agreements and instructions remain in the database.
The v0.17.45 employer review queue is retained by that rollback.
New document wording continues to use the existing builder data format.
