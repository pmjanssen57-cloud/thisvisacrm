THiS CRM v0.17.21 - Agreement Issue Preview Hotfix

Built from v0.17.20.

Fixes
- Removes the obsolete browser-side signing-token generation from the Issue agreement button path. Signing links remain generated securely by the CRM backend only when Send agreement is selected.
- Wraps the Issue agreement preview in defensive error handling with visible status/toast feedback rather than allowing an uncaught JavaScript error to make the button appear unresponsive.
- Makes the current To/CC routing visible in the preview exactly as introduced in v0.17.20.
- Adds a clear Issuing state to Send agreement and restores the button if no confirmation is received.
- Advances both Agreement Studio HTML and JavaScript cache versions to v0.17.21 so browsers cannot continue using an older Studio shell.

Database
- No migration. Existing 44 migrations are unchanged.
