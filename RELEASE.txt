THiS CRM v0.15.10 - Agreement Load and Print Flow Hotfix

Baseline
- Built from v0.15.9 Agreement Acceptance Visibility Hotfix.
- This remains the pre-unified-client-editor branch so the agreement fixes can be verified before merging v0.15.8.

Changes
- Opening one agreement now fetches only that agreement and its secure signatory records instead of returning the entire CRM dataset.
- Agreement workspace status refreshes now return list metadata only; large Studio snapshots are fetched on demand.
- Signed-agreement signature and acceptance visibility from v0.15.9 is retained.
- Agreement print pages now include a small physical-page safety reserve to prevent each generated A4 sheet spilling onto an extra browser print page.
- Print mode no longer applies section-level break-inside avoidance on top of the Studio paginator.
- Final-page print sizing is constrained to the physical page rather than inheriting the screen-only 1123px minimum.
- Fee table rows remain protected from splitting mid-row.

No database migration, dependency or environment-variable changes.
