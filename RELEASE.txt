THiS CRM v0.17.20 - Adviser Cleanup + Faster Assessment Flow

Baseline
- Built from v0.17.19 Assessment Review & Validation Polish.
- Retains assessment draft/resume, second citizenship, full final review, My Work workflow, streamlined matter updates and all existing CRM functionality.

Adviser cleanup
- Clearly unused New adviser profiles now show Remove unused directly on the adviser card.
- Fixes the New adviser creation flow so the temporary placeholder is removed after the real adviser profile is saved; this prevents future duplicate blank New adviser cards.
- Admins can also select Delete unused profile while editing an adviser with no primary or backup matters.
- Server-side deletion is deliberately conservative: it refuses deletion if the adviser is referenced by client matters, commercial matters, enquiries, tasks, calendar entries, agreements, booking links or bookings.
- The adviser linked to the current login cannot be deleted.
- Historical/former advisers should still be marked Inactive rather than deleted.
- Deleted adviser IDs are removed from website-notification recipient settings.

Assessment flow simplification
- Removes the four-second Kiwi fact/interstitial popup between every assessment stage.
- Next, Back and stage navigation now move immediately between sections.
- Removes the duplicate journey-map strip so the form reaches the actual questions sooner.
- Retains the clear eight-step progress tabs and compact current-step guide.
- Adds a small reassurance that applicants can move straight through and save for later at any time.
- No assessment questions or collected data have been removed in this release; this is a low-risk first simplification pass aimed at reducing friction and perceived length.

Database
- No new migration.
- All 44 migrations from v0.17.19 remain unchanged.
