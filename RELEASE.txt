THiS CRM v0.17.15 - Update Matter Modal Hotfix

Baseline
- Direct hotfix to v0.17.14 Simple Matter Update + Advanced Editing.
- All v0.17.14 workflow, mobile, notification, client workspace and styling changes are retained.

Fix
- Restores the missing MATTER_UPDATE_EVENTS preset list used by the new Update Matter modal.
- In v0.17.14 the modal referenced this list at render time even though it had not been declared, causing the React client workspace to crash to a blank screen when Update matter was opened.
- The modal now renders the intended preset event choices: Reviewed documents, Documents received, Application prepared, Application submitted, INZ update received, Further information requested, Response submitted, Application approved, Spoke with client, and Other.

Database
- No migration or schema change.
- All existing 43 migration files are unchanged.
