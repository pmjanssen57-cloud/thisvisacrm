THiS CRM v0.17.47 — Calm precision
Built from the completed v0.17.46 release, 20 October 2026.

INTERFACE
- Implements the approved Calm precision direction: light sidebar, white workspace,
  forest-green actions, larger readable typography, clear hierarchy and restrained borders.
- Restores the supplied THiS logo and the Studio section name.
- Desktop navigation remains fully expanded, including at tablet/laptop desktop widths.
- My Work uses clear action counts, client initials, next-action rows and compact empty states.
- Waiting matters remain visible even when their review dates are in the future.
- Today's appointments appear alongside waiting matters, using the actual appointment time.
- Add task opens a focused editing panel, protects unsaved changes and retains failed saves.
- Existing List/Board views, responsibility/date filters and shortcuts remain available.
- Shared styling carries through client records, enquiry reviews, task/calendar editing,
  commercial records, Studio lists and both agreement/instructions builders.
- Public intake, employer accreditation and contact forms use matching readable controls,
  spacing, fields and restrained surfaces. The decorative intake journey map is removed
  from the screen; the guided steps and existing form logic remain available.

MOBILE
- Responsive navigation and stacked content with readable labels and touch-friendly actions.
- Mobile editing panels fill the available visual viewport, including after viewport resizing.
- Scrollable form content with reachable panel footers and safe-area spacing.
- Mobile form fields use at least 16px text to avoid focus zoom on common phone browsers.
- Both builders retain Sections/Edit/Preview modes and fitted document previews.

PRESERVED
Employer questionnaire inbox, duplicate/draft visibility, matching, explicit attach/create,
tax/accreditation/key-people/history/document transfers, audit and processed links.
Original agreement and instructions document engines, output content and print layouts.
All 24 Netlify function modules remain byte-for-byte identical to v0.17.46.

MIGRATION / SCHEMA STATUS
No new migration. No schema change from v0.17.46, v0.17.45 or v0.17.44.
All 47 existing SQL migrations are byte-for-byte unchanged.
A database already at v0.17.44 or later needs no additional SQL for this release.
Older databases still require the existing baseline migrations, including
202610190001_add_employer_accreditation_questionnaire.sql.
No live database was connected or modified during preparation.

DEPLOYMENT
This is a Netlify source release. Extract with package.json, netlify.toml, App.jsx,
main.jsx, public, src and netlify at the root. Use the existing Netlify build workflow:
yarn build; publish dist; functions netlify/functions. Keep existing environment settings
and database/blob stores. A frontend-only static upload does not deploy the functions.
Local dependencies, test harnesses and generated dist output are excluded from the ZIP.
PWA cache advances to this-crm-shell-v0.17.47; precision-studio.css is precached.
No production deployment has been performed.

ROLLBACK
THiS-CRM-v0.17.46-ROLLBACK.zip is an exact copy of the completed v0.17.46 source ZIP.
Redeploy using the same Netlify build workflow. No database rollback or SQL deletion.
Existing records, questionnaire links, documents and agreements remain in the database.
