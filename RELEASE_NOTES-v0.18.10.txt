THiS CRM v0.18.10 - Blank Instructions Builder
23 November 2026

BASELINE: THiS CRM v0.18.09 - Delegated Client Tasks.

WHAT CHANGED
- New "Blank instructions - create your own" type in CRM Instructions Studio creation and in the document category selector.
- Starts with one guide and an editable introduction, no visa-specific blocks.
- Reuses the existing THiS branded cover page, photo handling, rich-text editing, numbered sections, reorder/remove actions, reusable blocks and PDF/print.
- The blank guide Output settings provide editable cover heading and category/cover subtitle. Prepared-for and date use the existing client and issue fields; cover image can be uploaded.
- In the blank editor: New blank guide, Duplicate existing guide, Use saved master, Save / publish master.
- Duplicate copies any existing built-in category guide as a separate editable blank document; the source is not modified.
- Published reusable masters are stored under separate blank-UUID identifiers in the existing administrator-managed shared instruction-template library, retaining a change note and version history (up to ten versions). Loading one creates a separate client draft; changing the client draft does not change its published master.
- Publishing requires Admin access to the team library and an explicit confirmation that client-specific material was removed. Normal client drafts continue through the existing CRM save workflow.
- No database schema migration required.

TESTING
- JavaScript syntax checks passed for the modified Instructions Studio, builder and shared library scripts.
- Structural checks confirmed the blank category, empty starting guide, workflow controls, master storage hooks and new CRM pack option.
- ZIP integrity checked.
- Browser automation could not run because navigation to the test server was blocked in this environment.
- Full Vite production build and live Netlify/database/PDF end-to-end tests remain outstanding.

IMPORTANT
- Shared master publication is restricted to Admin, consistent with existing team-library permissions.
- No separate personal reusable-master storage is introduced; non-admins may use published team masters and save individual client drafts.
- Team library storage has a 2.5 MB server limit, so extremely large uploaded cover photographs or many revisions can require image compression/archival.
- Always review client-specific wording, merge fields and images before publishing as a reusable master.

DEPLOYMENT
- Use a Netlify deploy preview first. Create a new blank instructions set for a sample client; change cover title/subtitle, upload image, add/reorder blocks, save and reopen, and print to PDF.
- As Admin, publish a named blank master with a change note. Load it into a second sample client and verify the first document and master remain unchanged.
- Confirm the previous visa-category instructions and v0.18.09 delegated tasks still work.
